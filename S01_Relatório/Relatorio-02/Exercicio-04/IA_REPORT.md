# IA Report

Durante o desenvolvimento do programa, tive dúvidas sobre como organizar a lógica para executar diferentes operações utilizando uma única função principal. Utilizei uma IA, que sugeriu a criação da função `analisarNumeros`, responsável por receber os dados de entrada e decidir qual subfunção deveria ser chamada com base na operação informada pelo usuário.

Com essa abordagem, consegui separar melhor as responsabilidades do programa, deixando cada cálculo em uma função específica e centralizando a tomada de decisão na função principal. Essa experiência ajudou a compreender conceitos de modularização e organização de código em Lua.
